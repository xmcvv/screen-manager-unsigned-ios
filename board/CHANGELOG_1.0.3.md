# 1.0.3 仪表帧率与粒子连续性修复

日期：2026-11-14

## P4 固件

- 版本：`SD5580 P4 matrix-v4`
- 文件：`sd5580_link.bin`
- 大小与 MD5：以交付目录 `校验值.md` 为准

## 卡顿根因

- UI 主循环每 6 ms 调用一次 `lv_refr_now()`，绕过 LVGL 刷新合并。
- LVGL 被设置为 `full_refresh=1`，任何小区域变化都会重绘整张 800×480。
- 新增的 4% 全屏透明遮罩成为 LVGL 的最高覆盖层，局部刷新无法正确取到
  底层壁纸，进一步迫使其扩大重绘范围。

## 修复内容

- 恢复 LVGL 局部刷新，刷新周期设为 16 ms。
- 删除全屏透明 LVGL 遮罩，把同样的亮度处理直接烘焙进 RGB565 壁纸缓冲。
- UI 任务不再强制整屏刷新，由 LVGL 合并数字、触摸反馈和动画失效区域。
- 急加速动画保持约 2 秒，帧间隔从 50 ms 提升到 33 ms。
- 粒子改为持续循环：粒子到达边缘后淡出并重新从中心发射，直到动画退出。
- 充电绿色点阵继续复用同一套固定粒子表和局部背景合成路径。

## 真机验证

- 固件通过 5580 异步 OTA 接口升级。
- P4 USB 心跳持续在线。
- 日夜主题和远程序列亮度命令下发后未断链。
- 动画的实际流畅度、粒子连续性以及是否仍有文字残影需要屏幕前最终验收。
