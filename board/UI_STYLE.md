# 仪表点阵能量 UI

## 视觉方向

- 黑色或低亮度壁纸底图
- 大面积琥珀色 `RGB565` 点阵能量场
- 中央大号白色车速
- 顶部绿色 `READY`、挡位和驾驶模式
- 左右两列共六个可配置指标
- 底部青色电池条、百分比、续航、温度和时间
- 告警只在有事件时横贯顶部，不长期占用画面

## 布局

| 区域 | 内容 |
|---|---|
| `y 12..48` | READY、PRND、ECO/STD/SPORT、连接状态、CarPlay、主题 |
| `y 64..84` | 告警条，仅故障时显示 |
| `y 92..388` | 琥珀点阵能量场 |
| `x 250..550` | 中央车速、km/h、动态能量线 |
| `x 38..184` | 左侧三个指标 |
| `x 616..762` | 右侧三个指标 |
| `y 408..438` | 电池、续航、里程、温度、时间 |

## 背景与加速动画

正常行驶时直接显示壁纸；没有壁纸时显示纯色背景，点阵不会长期覆盖画面。

检测到约 `4.5 km/h/s` 以上的急加速时：

1. 暂时隐藏顶部、左右指标、底部状态栏和辅助信息。
2. 只保留三位数车速和点阵动画。
3. 每次急加速只触发一次，点阵亮环从画面外缘向中心汇聚，持续约 0.96 秒。
4. 点阵颜色跟随当前挡位/驾驶模式的强调色。
5. 动画结束后恢复全部模块和壁纸背景。

动画帧缓存在 PSRAM，普通遥测更新不会重绘整张点阵背景。

## 充电状态

- 隐藏底部电池条和普通仪表模块。
- 中央显示大号 SOC、百分比和水平电池电量条。
- 电量条上有循环移动的充电动画。
- 充电结束后恢复正常驾驶仪表。

## 交互

- 六个左右指标均可点击，进入原有指标趋势详情页。
- 自定义指标槽位继续由 App 的九字节布局协议控制。
- 隐藏槽位会连同标签、数值和强调线一起隐藏。
- CarPlay 入口、主题按钮和充电页保持原功能。
