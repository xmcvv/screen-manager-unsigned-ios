# 仪表点阵能量 UI

## 视觉方向

- 壁纸固定为最底层；其上是一层肉眼几乎不可见的约 4% 黑色遮罩，再往上才是
  仪表控件和文字。
- 大面积 `RGB565` 点阵能量场与中央大号车速构成主视觉。
- 顶部显示 `READY`、挡位、驾驶模式、亮度、USB、Wi-Fi、主题和 CarPlay。
- 左右两列共六个可配置指标；数值使用 32 px 粗体，标题使用 18 px 粗体并随
  日夜主题反色。
- 所有仪表文字使用统一柔和外阴影，保证在复杂壁纸上仍然清晰。

## 布局

| 区域 | 内容 |
|---|---|
| `y 12..48` | READY、PRND、ECO/STD/SPORT、亮度、连接状态、CarPlay、主题 |
| `y 64..84` | 告警条，仅故障时显示 |
| `y 92..388` | 点阵能量场与中央车速 |
| `x 38..184` | 左侧三个指标 |
| `x 616..762` | 右侧三个指标 |
| `y 408..438` | 电池、续航、里程、温度、时间 |

## 急加速动画

检测到约 `4.5 km/h/s` 以上的急加速时：

1. 暂时隐藏顶部、左右指标、底部状态栏和其他辅助模块。
2. 只保留三位数车速、红色粒子和拖尾。
3. 粒子从画面中心向四周平铺扩散，不绘制亮环、光晕或伪立体纵深。
4. 每帧都有一批新粒子从中心出生，每颗粒子只播放一次、不循环回收；
   持续到 2.0 秒动画退出，帧间隔约 33 ms。
5. 同一轮加速只触发一次，冷却时间不少于 2.0 秒。

动画直接在 PSRAM 的 RGB565 壁纸缓冲中生成，避免大量 LVGL 控件同时移动。

## 性能约束

- LVGL 使用局部刷新，只重绘发生变化的数字、图标和触摸反馈区域。
- 刷新周期限制在约 16 ms，禁止在 UI 主循环中每 6 ms 强制整屏刷新。
- 4% 可读性遮罩直接烘焙进壁纸 RGB565 缓冲，不能再用全屏透明 LVGL 对象；
  后者会被判定为覆盖层，导致每次小文字变化都重画整屏。
- 加速和充电粒子的方向、速度提前计算，播放时不在每帧做三角函数或动态分配。
- LVGL 呈现使用两块 DPI framebuffer 交替扫描，避免 PPA 在面板扫描上半屏时
  覆盖当前帧造成上半部分花屏。

## 充电状态

- 隐藏普通仪表模块，取消横向电量条。
- 中央只显示大号 SOC、百分比、充电功率和预计时间。
- 绿色点阵从画面外缘持续向中心收缩，形成充电能量汇聚动画。
- 充满后停止动态粒子，显示 `CHARGE COMPLETE`；退出充电后恢复驾驶 UI。

## 亮度

- 顶部 `BRI` 按钮打开亮度面板，滑杆范围 20%–100%。
- 背光使用 LEDC PWM 调光，并按近似平方曲线做视觉亮度补偿。
- 手动亮度写入 NVS，重启后保持。
- 自动亮度接口已预留：环境光传感器或摄像头测光模块取得有效 lux 后调用
  `ui_report_ambient_lux()`，由固件自动映射到安全亮度区间。
- 当前屏幕本体只提供 15-pin MIPI CSI 摄像头接口，没有内置光线传感器；
  自动亮度需要接入已知型号的摄像头模块并实现 CSI 测光。

## 交互

- 六个指标均可点击进入趋势详情页。
- 自定义指标槽位继续由 App 的九字节布局协议控制。
- 主屏手动日夜切换保留，文字黑白随主题反转。
- CarPlay 入口、主题按钮和充电页保持原功能。
