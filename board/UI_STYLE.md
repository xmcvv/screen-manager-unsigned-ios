# 仪表点阵能量 UI

## 视觉方向

- 黑色或低亮度壁纸底图
- 大面积琥珀色 `RGB565` 点阵能量场
- 中央大号白色车速
- 顶部绿色 `READY`、挡位和驾驶模式
- 左右两列共六个可配置指标
- 底部青色电池条、百分比、续航、温度和时间
- 告警只在有事件时横贯顶部，不长期占用画面

## 布局

| 区域 | 内容 |
|---|---|
| `y 12..48` | READY、PRND、ECO/STD/SPORT、连接状态、CarPlay、主题 |
| `y 64..84` | 告警条，仅故障时显示 |
| `y 92..388` | 琥珀点阵能量场 |
| `x 250..550` | 中央车速、km/h、动态能量线 |
| `x 38..184` | 左侧三个指标 |
| `x 616..762` | 右侧三个指标 |
| `y 408..438` | 电池、续航、里程、温度、时间 |

## 背景

点阵背景在 P4 启动或壁纸提交时生成一次：

1. 如果存在有效壁纸，使用约 10% 亮度作为底层。
2. 中央叠加低强度琥珀径向光晕。
3. 按 14 px 网格绘制点阵，中心保留速度数字的暗区。
4. 点大小和亮度按到中心的距离变化，形成能量隧道效果。

背景缓存在 PSRAM，不会在每帧遥测更新时重绘整张位图。

## 交互

- 六个左右指标均可点击，进入原有指标趋势详情页。
- 自定义指标槽位继续由 App 的九字节布局协议控制。
- 隐藏槽位会连同标签、数值和强调线一起隐藏。
- CarPlay 入口、主题按钮和充电页保持原功能。
