## 已知限制

1. P4 当前擦除并提交 800×480 RGB565 壁纸约需 60–90 秒。App 已在进度达到
   100% 后显示“P4 正在擦除并写入”，请求超时放宽到 5 分钟。
2. Android 包使用 debug/preview 证书签名，可直接侧载测试，不适合商店正式发布。
3. IPA 必须在 macOS + Xcode 或 EAS + Apple Developer 凭据下生成。
4. CarPlay 当前连接状态取决于 iPhone 会话；本次验收时车机处于 connecting，
   没有进行新的 iPhone 配对。
5. App 管理数据使用车机本地 HTTP，不下发到云端；局域网内应只连接可信热点。

## 使用

1. 手机连接 `SD5580-CARPLAY`。
2. 打开车屏管家。
3. 默认访问 `http://192.168.4.1:8080`。
4. 若地址不同，在“连接设置”中修改并测试。
