# 车屏管家安装与连接

## Android

安装：

```text
ScreenManager-v1.0.1-android-arm64.apk
```

适用于 Android 7.0 (API 24) 及以上、arm64 手机。

首次使用：

1. 打开手机 Wi-Fi。
2. 连接 `SD5580-CARPLAY`。
3. 打开车屏管家。
4. 默认管理地址为 `http://192.168.4.1:8080`。
5. 地址不一致时，在右上角设置中修改并测试。

如果 Android 提示“未知来源”，这是预览签名 APK 的正常安装提示。

1.0.1 修复了壁纸/固件上传超时后连接状态被误判离线的问题。上传和 P4
写入期间 App 会保持在线状态，后台状态轮询失败三次后才会显示离线。

## iOS

公开仓库通过 GitHub macOS runner 生成 arm64 未签名 IPA：

```text
ScreenManager-v1.0.1-ios-trollstore-unsigned.ipa
```

推荐使用 TrollStore 安装，不需要 Apple Developer 账号。1.0.1 将大文件上传
改为前台 URLSession，并在异常路径释放原生任务，修复上传失败后后台继续重试
以及 iOS 闪退。

应用首次访问局域网时，iOS 会请求“本地网络”权限，必须允许。

## 管理功能

- 概览：P4、USB、Wi-Fi、CarPlay、实时仪表和快捷操作
- 车况：速度趋势、动力、电池、温度、资源与告警
- 仪表：六个槽位换指标、排序、显隐、日夜主题
- 管理：壁纸和 P4 固件

壁纸提交后 P4 还需约 60–90 秒擦除和写入。5580 会立即接收上传并返回任务状态，
App 随后轮询真实进度，不再让 HTTP 请求一直等待 Flash 擦除完成。
