# 车屏管家安装与连接

## Android

安装：

```text
ScreenManager-v1.0.0-android-arm64.apk
```

适用于 Android 7.0 (API 24) 及以上、arm64 手机。

首次使用：

1. 打开手机 Wi-Fi。
2. 连接 `SD5580-CARPLAY`。
3. 打开车屏管家。
4. 默认管理地址为 `http://192.168.4.1:8080`。
5. 地址不一致时，在右上角设置中修改并测试。

如果 Android 提示“未知来源”，这是预览签名 APK 的正常安装提示。

## iOS

当前 Windows 主机不能生成已签名 IPA。iOS 源工程和 EAS 配置完整可用，分为两种构建方式：

- 在 macOS 上：执行 `npx expo run:ios`
- 使用 EAS：执行 `npx eas-cli@latest build --platform ios --profile preview`

生成 IPA 需要 Apple Developer 账号和签名凭据。

应用首次访问局域网时，iOS 会请求“本地网络”权限，必须允许。

## 管理功能

- 概览：P4、USB、Wi-Fi、CarPlay、实时仪表和快捷操作
- 车况：速度趋势、动力、电池、温度、资源与告警
- 仪表：六个槽位换指标、排序、显隐、日夜主题
- 管理：壁纸和 P4 固件

壁纸提交后 P4 还需约 60–90 秒擦除和写入，App 会继续等待并显示该状态。
